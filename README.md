# Prompts-Library

## GitHub Copilot prompt files

Store reusable prompt files in [`.github/prompts`](.github/prompts) with the
`.prompt.md` extension, following the
[official VS Code documentation](https://code.visualstudio.com/docs/agent-customization/prompt-files).
The `.gitkeep` file keeps the empty folder tracked until prompts are added.

To run a prompt in VS Code, type `/` in Copilot Chat and select its name, or run
**Chat: Run Prompt...** from the Command Palette.
